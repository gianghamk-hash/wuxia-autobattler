# Art direction — mobile UI 1.1

Created for Võ Lâm Hài Hiệp Truyện on 2026-11-05 with the built-in image generation tool. These are original generated illustrations; no third-party game artwork or external image service is used.

- `jianghu-village.webp`: background for the title, camp, story and battle backdrop; 1536 × 1024, 487,082 bytes.
- `sect-portraits.webp`: five equal-width representative sect portraits, left to right: Thiếu Lâm, Võ Đang, Cái Bang, Nga Mi, Đường Môn; 1983 × 793, 302,744 bytes. Same-sect characters reuse this art. This is not a set of twenty individual companion portraits.
- `game-mark.svg`: code-native application emblem. UI icons are code-native SVG paths in `src/ui/Visuals.js`.

The generated PNG originals were encoded as WebP at quality 82 for the repository. Production consumes only the two optimized files. The illustration atlas is cropped in CSS/Canvas at runtime; it contains no UI or baked text.

## Environment prompt

Use case: stylized-concept. Asset type: production background illustration for an original Vietnamese-language wuxia mobile RPG, landscape 1536x1024. A beautiful bustling ancient Chinese mountain village and martial arts inn at golden dawn, elegant curved tile roofs, cherry blossom tree framing upper left, teal mountain layers and waterfall in the far distance, stone stairs leading into village, two tiny travelers near an inn. Premium mobile game splash art, hand painted detailed anime cel shading with rich atmospheric light, jade teal foliage, warm ivory clouds, red lantern accents, warm gold sunlight, crisp rich architectural detail, inviting adventurous mood with playful charm. Composition: panoramic environmental background only, no large foreground people, open lighter sky in upper center for game title overlay, detailed inn buildings toward right, path and garden to left; entire environment full bleed. NO TEXT, NO LETTERS, NO logos, no UI, no borders, no watermark. This is a usable in-game environment asset, not a UI mockup.
